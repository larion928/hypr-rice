# hypr-rice

**Русский** · [English](README.en.md)

Готовый рабочий стол для Arch Linux: Hyprland 0.57+ (конфиг на Lua), меню и окна на Quickshell, панель
Waybar. Девять тем. Тема меняет всё сразу: цвета и шрифты, анимации окон, обои, экран блокировки и экран
входа SDDM, меню, панель, окно громкости, анимацию и звук скриншота, а также оформление программ.

![темы](docs/themes.jpg)

## Установка

На свежем Arch (или производном: CachyOS, EndeavourOS и т.п.) войди под своим обычным
пользователем и выполни:

```sh
curl -fsSL https://raw.githubusercontent.com/larion928/hypr-rice/main/install.sh | bash
```

Установщик сначала задаёт все вопросы, дальше работает сам:

1. **Пароль sudo.** Один раз в начале.
2. **Старый райс.** Если уже настроено другое окружение (`~/.config/hypr`, `waybar`, `rofi`,
   `dunst`…), спросит разрешения и уберёт его в `~/.rice-backup-<дата>/`. Ничего не удаляется.
3. **Программы.** Список с галочками (пробел — отметить, Enter — дальше), по умолчанию ничего не
   отмечено: браузеры (Firefox, Chromium, Brave, Zen, LibreWolf, Vivaldi), AyuGram, Telegram,
   Discord, Steam, Proton для `.exe`, osu!, Prism Launcher, Claude Code, Code-OSS, OBS,
   LibreOffice, Happ и другие, всего около сотни. Полный список: [`packages/apps.txt`](packages/apps.txt).
4. **Установка.** Hyprland и всё нужное райсу, конфиги, экран входа SDDM (с Hyprland
   по умолчанию), тема GTK, иконки, курсор WhiteCat, сервисы, Fn Lock на Lenovo IdeaPad, тема claude.

После этого перезагрузись: откроется экран входа с выбранным Hyprland.

### Если уже стоит другое окружение

Если найден другой райс или рабочий стол (niri, KDE, GNOME, другой Hyprland…), установщик спросит:

- **Заменить.** Старые настройки уходят в `~/.rice-backup-<дата>/`, по умолчанию будет Hyprland.
- **Поставить рядом.** Чужие настройки не трогаются, выбор окружения — на экране входа. Свои
  waybar и kitty райс держит в `~/.config/hypr-rice/`, демон уведомлений и портал запускаются
  только в Hyprland, у другого окружения остаются его `~/.config/waybar`, `kitty`, `mako`, `fish`.
  Заменяется только чужой конфиг Hyprland, если он был (два райса в одном Hyprland не живут).
  Общей остаётся тема GTK (Thunar, окна выбора файлов): её меняют оба окружения.
  Экран входа можно оставить свой — Hyprland появится в его списке сеансов.

### Если что-то заблокировано

- **AUR недоступен** (ошибки вида `TLS connect error … unexpected eof`). Ничего делать не нужно.
  AUR-пакеты берутся готовыми из [hypr-rice-pkgs](https://github.com/larion928/hypr-rice-pkgs):
  их собирает GitHub раз в неделю, они подписаны. Если какого-то пакета там нет, его рецепт
  скачивается с зеркала AUR на GitHub и собирается на месте.
- **Зеркала pacman подвисают** (`Operation too slow`). Установщик повторяет загрузку до 6 раз,
  со второй попытки переключается на запасные зеркала (старый список сохраняется в
  `/etc/pacman.d/mirrorlist.rice-backup`).

## Темы

`claude`, `night`, `hacker`, `cyberpunk`, `frieren`, `sakura`, `coffee`, `ocean`, `mr-robot`.

Сменить тему: Alt+Shift+T (карточки тем в их собственных цветах), лаунчер («Тема …») или
`changetheme <тема>` в терминале.

Под тему подстраиваются программы:

- **Браузеры.** Firefox, Zen и LibreWolf: цвета, шрифт, скругления, обои за вкладками, значок темы
  вместо кнопки меню, новая вкладка с обоями и названием темы. Chromium, Brave и Chrome: тема с
  цветами, обоями на новой вкладке и значком. Браузеры подхватывают тему при следующем запуске.
- **Остальные.** Code-OSS, AyuGram и Telegram, Discord (Vesktop), Obsidian, kitty, GTK и Thunar,
  drift, neoHtop.

Любую тему можно поправить под себя: Alt+F2 → Тема → тема → «Изменить». Там шрифты, цвета
(и цвет папок Papirus), обои, раскладка панели, тема значков и рисунок батареи, курсор, окна
(отступы, рамка, скругление, прозрачность, размытие, скорость анимаций). Сохраняются только отличия
от темы, «Сбросить» возвращает её как была. Темы можно копировать, экспортировать в файл и импортировать.

**Обои.** У темы несколько обоев, их можно добавлять, выключать и удалять. Обои бывают анимированные:
GIF или видео, а также видео-обои из Wallpaper Engine, на которые ты подписан в Steam Workshop (сцены
Wallpaper Engine — это программы, их добавить нельзя). Анимированные обои замирают, пока их целиком
закрывают полноэкранные окна (игра, видео): меньше нагрузка.

## Панель

Модули панели кликабельные:

| Модуль | Клик |
|---|---|
| сеть | панель Wi-Fi: сети, пароль прямо в строке, текущее подключение и VPN, «забыть сеть»; правый клик — nmtui |
| звук | pavucontrol |
| плеер | карточка плеера (см. ниже) |
| телефон | меню телефона (см. ниже); заряд — пока сопряжённый телефон на связи |
| режим питания | экономия → баланс → производительность |
| батарея | правый клик — сбережение батареи (Lenovo IdeaPad) |
| обновления | появляется, когда они есть; клик — `rice upgrade` |
| колокольчик | история уведомлений |
| камера | галерея скриншотов |
| шестерёнка, «?», палитра, выключение | настройки, справка, выбор темы, меню выхода |

Раскладка панели меняется перетаскиванием: Alt+F2 → Тема → тема → «Изменить» → Панель. Там же
модули, которых нет на панели по умолчанию (трей, Bluetooth, яркость и другие), значки модулей и
положение панели сверху или снизу. Раскладку можно сохранить для одной темы или для всех.

## Меню

Все меню открываются в цветах и шрифтах текущей темы, повторное нажатие той же клавиши их закрывает,
Esc тоже.

| Меню | Как открыть | Что там |
|---|---|---|
| Лаунчер | Alt+R | программы и команды райса: темы, настройки, сеть, питание, выход; поиск понимает текст, набранный не в той раскладке |
| Настройки | Alt+F2 | мониторы, клавиши, темы, функции (ниже) |
| Справка | Alt+F1 | все горячие клавиши, собранные из конфига, и файлы своих настроек |
| Выбор темы | Alt+Shift+T | все темы карточками |
| Выход | Alt+M | блокировка, выход, сон, перезагрузка, выключение (опасное — со второго нажатия) |
| Игры | Alt+G | библиотека игр (ниже) |
| Буфер обмена | Alt+Shift+V | последние 100 скопированных записей, поиск; включается в Функциях |
| Уведомления | колокольчик | история по дням, поиск, «не беспокоить» |
| Плеер | модуль «Плеер» на панели | обложка, трек, перемотка, кнопки, громкость, выбор источника, когда играет несколько программ |
| Скриншоты | камера на панели | все снимки, просмотр, копировать, удалить |
| Телефон | модуль «Телефон» на панели | KDE Connect: заряд, найти телефон, пинг, отправить файлы и буфер обмена, файлы телефона в Thunar, сопряжение; включается в Функциях |

Медиаклавиши управляют тем же плеером, что показан в карточке. Когда программе нужны права
администратора, пароль спрашивает окно в стиле темы. Громкость и яркость показывает окно темы.

## Скриншоты

| Клавиши | |
|---|---|
| Print | область (тянуть) или окно (клик), Enter — весь экран, Esc — отмена |
| Shift+Print | весь монитор сразу |
| Alt+Shift+Print | распознать текст в области (русский и английский), текст — в буфер |
| Alt+Shift+C | пипетка: лупа над экраном, клик копирует цвет точки как `#rrggbb` |

Снимок сохраняется в `~/Pictures/screenshots` и копируется в буфер. У каждой темы своя анимация
и звук снимка.

## Настройки (Alt+F2)

Окно настроек открывается по Alt+F2, шестерёнкой в панели или из лаунчера.

- **Мониторы.** Расположение перетаскиванием, разрешение, частота, масштаб, включить/выключить.
  Применяется сразу; если за 15 секунд не нажать «Оставить», всё вернётся как было.
  Сохраняется в `~/.config/hypr/monitors.lua`.
- **Клавиши.** Изменить любую горячую клавишу (нажал «Изменить» → нажал новое сочетание),
  выключить, вернуть, добавить свои «сочетание → команда», сменить главную клавишу Alt ↔ Super.
  Занятые сочетания подсвечиваются. Твои изменения лежат в `~/.config/hypr/binds-user.lua`.
- **Тема.** Все темы, правка темы (см. «Темы»), импорт, копирование, экспорт, сброс, удаление.
- **Функции.** Части райса, которые можно выключить. Если функции нужен пакет, окно предложит его
  поставить. То же из терминала: `rice features`.

| Функция | По умолчанию |
|---|---|
| Анимации окон | вкл |
| Анимация скриншота, звук затвора | вкл |
| Распознавание текста, пипетка | вкл |
| Свайп тремя пальцами по тачпаду — соседний рабочий стол | вкл |
| Размытие под меню | вкл |
| Пауза анимированных обоев под полноэкранными окнами | вкл |
| Ежедневная проверка системы (`rice doctor`, уведомление о найденном) | вкл |
| Автомонтирование USB-дисков (значок в трее, извлечь — из него или в Thunar) | вкл |
| Уведомления о дисках | выкл |
| Телефон (KDE Connect): меню и заряд на панели; если ufw закрывает порты 1714–1764, окно предложит их открыть | выкл |
| История буфера обмена (стирается при выключении) | выкл |
| Исправление раскладки: Alt+Shift+Пробел — последнее слово в другой раскладке (ещё раз — обратно), Alt+Ctrl+Пробел — выделенный текст; нужна группа `input`, окно предложит добавить | выкл |
| Автоисправление раскладки: слово не в той раскладке исправляется после пробела по словарям (русский, английский); не в полноэкранных окнах и не в программах из `exclude` в `~/.config/hypr-rice/layout-fix.json` | выкл |
| Исправление опечаток: Alt+Shift+Пробел на слове, которого нет ни в русском, ни в английском словаре, — подсказки словаря по очереди (до 5, самые частые слова первыми), после последней — набранное слово | выкл |
| Прокрутка окон, экспериментальная: колонки в бесконечной ленте, как в niri; Alt+P — ширина колонки, Alt+Shift+P — уместить видимые; три пальца двигают ленту, четыре — рабочий стол | выкл |

## Игры

- **Библиотека** (Alt+G): игры карточками с обложками, поиск, запуск по Enter. Добавить можно `.exe`
  (запускается через Proton), AppImage, любой файл программы, установленную программу или игру из
  Steam. Библиотека лежит в `~/.config/hypr-rice/games.json`, обновления райса её не трогают.
- **`.exe` двойным кликом.** Windows-программы (`.exe`, `.msi`, `.bat`, `.lnk`) открываются через
  Proton. Версия Proton: `rice proton` (по умолчанию последняя UMU-Proton).
- **Оптимизация:** `rice games`, каждая включается отдельно. GameMode (приоритет процессора и диска
  на время игры), NTSync, тиринг для полноэкранных игр, ядро linux-zen.

## Устройства

- **Мышь.** `mouse-sens` — чувствительность вживую. `rice mouse-test` — ведёшь мышь вдоль линейки с
  зажатой левой кнопкой, тест измеряет угол датчика (и предлагает поворот, который его исправит),
  разрешение и частоту опроса. Настройки лежат в `~/.config/hypr/devices.lua`.
- **Флешки и карты памяти** подключаются сами (функция «Автомонтирование»).
- **Lenovo IdeaPad:** Fn Lock, сбережение батареи (зарядка до ~60%, правый клик по батарее).

## Система

- **Питание.** Экономия (без турбобуста, видеокарта на минимуме), баланс и производительность:
  модуль на панели или лаунчер (`power-mode`).
- **Обновления.** Значок на панели с числом обновлений (репозитории и AUR), клик запускает `rice upgrade`.
- **Проверка системы.** `rice doctor` ищет, что сломано, объясняет почему и что делать; `--fix`
  предлагает лечение. Раз в день проверка идёт сама и присылает уведомление, если что-то нашла.
- **Кэш пакетов** pacman и yay не растёт больше 200 МБ, SSD раз в неделю получает TRIM.
- **Подписанные обновления.** Каждый коммит райса подписан ключом автора. При первой установке ключ
  запоминается в `~/.config/hypr-rice/allowed_signers`, и `rice update` (как и повторный запуск
  установщика) не применит версию с GitHub, подписанную не им.

## Менеджер `rice`

После установки в системе остаётся команда `rice`. Её меню открывается в терминале или из
лаунчера («Менеджер райса»):

| Команда | Что делает |
|---|---|
| `rice apps` | доставить программы: тот же список, установленные уже отмечены |
| `rice remove` | удалить программы из списка |
| `rice update` | обновить райс с GitHub: его файлы и недостающие пакеты (тема и настройки этой машины сохраняются, систему не обновляет) |
| `rice upgrade` | обновить систему и программы, включая AUR |
| `rice features` | функции райса: список, `rice features on\|off <id>` |
| `rice games` | игровые оптимизации: GameMode, NTSync, тиринг, linux-zen |
| `rice proton` | какая версия Proton запускает `.exe`: последняя UMU-Proton (по умолчанию) или любая из ProtonPlus |
| `rice doctor` | проверить систему и райс; `--fix` — лечить, `--full` — и медленные проверки |
| `rice repair` | починить: экран входа SDDM, тема GTK, сервисы, функции |
| `rice mouse-test` | угол датчика мыши (и поворот, который его исправит), разрешение, частота опроса |
| `rice report` | собрать отчёт `~/rice-report.txt`, чтобы прислать тому, кто помогает |
| `rice uninstall` | убрать райс и вернуть настройки, которые были до него |

## Свои настройки

`rice update` заменяет файлы райса новыми версиями без бэкапа: бэкап делается только при первой установке.
Свои правки держи в этих файлах, обновление их не трогает:

| Файл | Что там |
|---|---|
| `~/.config/hypr/user.lua` | Hyprland: правила окон, автозапуск, переменные, любой Lua. Грузится последним, поэтому может переопределить что угодно. Применить: `hyprctl reload` |
| `~/.config/hypr/binds-user.lua` | горячие клавиши (пишет окно Alt+F2) |
| `~/.config/hypr/monitors.lua` | мониторы (пишет окно Alt+F2) |
| `~/.config/hypr/devices.lua` | мышь и тачпад (`mouse-sens`, `rice mouse-test`) |
| `~/.config/hypr-rice/theme-edits.json` | правки тем (пишет окно Alt+F2) |
| `~/.config/hypr-rice/features.json` | какие функции включены (пишет окно Alt+F2 и `rice features`) |
| `~/.config/hypr-rice/games.json` | библиотека игр (пишет окно Alt+G) |
| `~/.config/fish/user.fish` | fish: алиасы, `PATH`, переменные |
| `~/.config/hypr-rice/kitty/user.conf` | kitty: шрифт, прозрачность, свои клавиши |
| `~/.config/hypr-rice/waybar/user.css` | стили панели поверх темы. Применить: `waybar-start` |
| `~/.config/hypr-rice/waybar/config.local.json` | модули панели поверх `config.base.json` |

Этот же список есть в справке Alt+F1.

## Настройки установщика

Переменные окружения перед `bash`, например `curl … | RICE_THEME=ocean bash`:

| Переменная | |
|---|---|
| `RICE_THEME=ocean` | тема после установки |
| `RICE_APPS=steam,obs,firefox` | программы без окна выбора (`all` — все, `none` — никаких) |
| `RICE_ASSUME=y` | ответить «да» на все вопросы (для автоматической установки) |
| `RICE_MODE=coexist` | поставить рядом с другим окружением, не спрашивая (`replace` — заменить) |
| `RICE_BRANCH=dev` | ставить из другой ветки |

## Устройство репозитория

```
install.sh        загрузчик: скачивает репозиторий и запускает rice install

doctor/           rice doctor: проверки системы и райса и их лечение
sync.sh           (для автора) собрать райс в репозиторий и отправить в dev; --release выпускает в main
packages/         base.txt (репозитории), aur.txt, apps.txt (каталог программ)
home/             раскладывается в ~ ; __HOME__ заменяется на твою домашнюю папку
system/           root-помощник (цвет папок, SDDM, питание), конфиг SDDM, Fn Lock, ключ репозитория пакетов
tests/            run.sh — тесты менеджера и скриптов; python/ — тесты скриптов на Python;
                  qml/ — меню Quickshell вне экрана (что они делают — qml/BEHAVIOUR.md)
```

Тесты систему не меняют: у каждого пустой поддельный `$HOME`, pacman и sudo заменены заглушками.

Тема лежит в `home/.config/hypr/themes/<имя>/`: `palette.json`, `ui.json`, `hypr.lua`,
`style.css` (waybar), `histui.css`, `hyprlock.conf`, `screenshot.qml`, `battery.py` (значок батареи),
`shutter.wav` и обои. Конфиги программ генерируются из палитры скриптом
`~/.config/hypr/scripts/themegen.py`; код для каждой программы — в `scripts/apptheme/`.
Меню — `home/.config/quickshell/shell/`, одна оболочка Quickshell на все меню.
